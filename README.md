INX FUTURE INC EMPLOYEE PERFORMANCE ANALYSIS
PROJECT OVERVIEW
-This project analyzes employee performance data for INX Future Inc to identify patterns and factors associated with employee performance.

OBJECTIVES

1 Analyze employee performance across different departments and the job roles.
2 Explore factors that are associated with the employee performance ratings.
3 Build machine learning models to predict the employee performance.

TOOLS AND TECHNOLOGIES

1 Python
2 Pandas
3 NumPy
4 Matplotlib
5 Seaborn
6 Scikit-learn
7 Google Colab

PROJECT WORKFLOW

1. Data loading and preprocessing
2. Exploratory data analysis (EDA)
3. Data visualization
4. Machine learning model development
5. Model evaluation and comparison

MODELS

1 Logistic Regression
2 Decision Tree
3 Random Forest
4 Gradient Boosting

RESULTS
-Gradient Boosting achieved the highest accuracy among the models tested at approximately 93.75%.
